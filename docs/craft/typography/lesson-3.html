Lesson 3: Hierarchy needs more than one signal

A reader scanning a page decides what's a heading and what's a caption in a fraction of a second, before they've read a single word. If the only clue is a few extra pixels of size, that decision gets a lot harder to make at a glance.

An h1 is set at 18px, regular weight. The body text below it is 16px, regular weight. Both use the same typeface and color. Does this create a clear heading?

Using font size as the only signal of hierarchy is a common mistake: a heading that's only slightly bigger than body text, in the same weight, reads as an accident rather than a heading. Every level of hierarchy needs to be distinguishable by more than one property — size and weight, or size and color, not size alone.
