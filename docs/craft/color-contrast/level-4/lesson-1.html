Level 4, Lesson 1: Colorblindness isn't one thing

"Colorblindness" gets used as a single label, but it covers several different, unrelated ways someone's eyes can process color, and each one changes something different about what a screen looks like. Red-green deficiency is the pattern almost everyone means by the word, and it's the one most design advice is built around. Blue-yellow deficiency is a separate, much rarer pattern that confuses a completely different pair of hues instead. Full monochromacy — seeing no hue distinctions at all, only relative lightness — is rarer still. Design only for the first pattern, and a palette can still fail someone with one of the other two.

A team reads that "colorblind users can't tell red from green" and decides their color vision work is done as soon as red and green never sit next to each other. What does this miss?

Red-green deficiency is the most common pattern, which is why it dominates design advice, but it isn't the only one. Blue-yellow deficiency confuses an entirely different axis of color, and full monochromacy removes hue distinctions altogether. A palette that only avoids putting red directly next to green can still be unreadable to someone with one of those other two patterns.
