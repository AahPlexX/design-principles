Level 4, Lesson 2: Red/green status pairing is the most common real-world failure

Contrast ratio is about whether text is readable at all. A related but separate problem is relying on color alone to communicate something — passing the ratio doesn't help if the color itself is the only signal, and some readers can't distinguish it from its opposite.

A form marks invalid fields only by turning the border red — no icon, no error text. What's the problem?

Red/green color blindness is common enough that "just make it red" fails for a real share of users — and even for someone who can see it, a color change alone doesn't say what's wrong. Pair the color with an icon and specific error text so the meaning doesn't depend on color perception at all.
