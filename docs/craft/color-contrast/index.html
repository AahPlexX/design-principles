Contrast You Can Prove

Practice reading contrast ratios and catching pairs that fail before a user does — real ratios and real UI, level by level, each with instant feedback.

This course pairs with Color & Contrast — read that page first for the full explanation of the 4.5:1/3:1 rule and how the ratio is calculated. This is where you practice applying it.
