Level 5, Lesson 1: Dark mode isn't automatically higher contrast

Flipping a light theme into a dark one feels like it should come with better contrast for free — "dark mode" even sounds like an accessibility feature by name alone. But contrast is a property of one specific color sitting next to another, not of a theme's name. Automating the flip doesn't automatically preserve the ratio each pair had before.

A team builds dark mode by running every light-mode color through a script that inverts its lightness value. The muted timestamp text, which comfortably cleared the contrast minimum in light mode, ships in dark mode without a second look because "the script handles contrast." User testing finds the timestamps are nearly unreadable on the new dark background. What actually happened?

A contrast ratio is a fact about two specific colors together, not about a color in isolation or a theme's name. A mid-tone gray inverted alongside its background can end up much closer in lightness to that new background than it ever was to the old one — the ratio has to be measured again for the new pair, not assumed from the old one.
