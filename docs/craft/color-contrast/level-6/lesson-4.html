Level 6, Lesson 4: Translucent "glass" panels reintroduce the same problem

A frosted-glass panel — a semi-transparent, blurred surface layered over other content — looks like a solid card, but it isn't one. Whatever sits behind it still shows through, just softened, which means the panel inherits the same unpredictable background it was supposed to sit above.

A dashboard's settings panel uses a frosted-glass style: a semi-transparent white background with blur, floating over a page of scrollable content. Dark gray text inside the panel is checked once, while a light gray chart sits behind it, and passes. The team ships it. A user later scrolls the page so a dark navy chart sits behind the same panel instead. What's true about the panel's text now?

"Frosted glass" is still see-through — the blur changes how sharp the background looks, not how much of its color bleeds into the panel. A panel checked against one background and then placed somewhere its background can change (a scrolling page, a dynamic chart, switchable content) needs either a background opaque enough that what's behind it barely matters, or a check against the darkest and lightest content it will ever sit over — the same discipline text-over-photo needs, applied to a panel instead of an image.
