Level 7, Lesson 2: Dedicated checkers, e.g. WebAIM's contrast checker

DevTools can only compute a ratio for colors that already exist in a live page. Before code exists — while a color is still just two hex values in a style guide or a design file — a dedicated contrast checker lets you type both values in directly and get the same math back, plus a clear pass or fail for each text size and standard level.

A designer is finalizing a style guide and wants to confirm that a proposed label color, #9b9b9b, will pass against the card background, #f2f2f2, before any of it exists in code. There's no live page to inspect yet. What's the right tool for this moment?

A dedicated checker takes two colors as input and returns the ratio plus pass/fail for each text size and conformance level, with no DOM to inspect. That makes it the right tool during design review, style-guide work, or any time you're comparing colors that don't exist in code yet — you don't have to wait for a build to know if a pair is safe.
