Level 7, Lesson 1: Browser DevTools' color picker gives you the ratio for free

Every major browser's inspector already knows how to compute a contrast ratio. You don't need to leave the page, copy hex codes anywhere, or do any math by hand — click the small color swatch next to a color or background value in the styles panel, and the picker that opens shows the ratio for that exact pair, plus a marker for where the passing threshold sits.

You're inspecting a paragraph in Chrome DevTools and see color: #767676 in the styles pane, sitting on a white page background. Clicking the small color swatch next to #767676 opens a picker showing a ratio number, a gradient slider, and a line marking where this text's size needs to land to pass. What does this let you do that just reading the two hex codes off the page doesn't?

The color picker reads the element's actual background live, so the ratio it shows is for the real pair sitting on the real page — not two colors compared in the abstract. Dragging the slider shows, in real time, which nearby shades would pass, so you can find a fix without switching to a separate tool.
