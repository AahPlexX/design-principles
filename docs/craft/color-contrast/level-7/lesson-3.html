Level 7, Lesson 3: Check the color where it's actually used, not in isolation

A contrast ratio is only true for the exact pair it was measured against. The same text color can pass against one background and fail against another, so a single "verified" note in a style guide doesn't travel with that color into every place it later gets reused.

A style guide documents the link color #2b6cb0 as "verified, passes against white." Months later, an engineer reuses that same link color inside a light-blue info banner component with background #e3f2fd, assuming it's already been checked. What's the mistake?

A contrast ratio describes one specific pair of colors, not some inherent quality of the link color on its own. The white-background check says nothing about how that same blue reads against the info banner's light-blue background — that's a different pair, and it needs its own check, in the place it's actually used, before it ships.
