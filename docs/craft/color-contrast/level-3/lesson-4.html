Level 3, Lesson 4: Chart lines need contrast too

Not every line on a chart is carrying the same weight. A gridline is scaffolding — it helps you judge scale, but the chart still means something without it. A data line is different: if it's the only place a number lives, and it fades into the background, the information is gone, not just harder to see.

A dashboard's line chart plots weekly revenue as a thin, pale-yellow line on a white background. There's no data table, no labels on the line itself, and no legend value readout — the line is the only place this number appears. A teammate says: "it's just a chart, not text or a button, so contrast rules don't apply." What's the issue with faint gridlines versus this line?

Purely decorative marks — gridlines, background scaffolding — don't carry a contrast requirement, because losing them doesn't lose information. A data line with no other way to read that value is different: it's a graphical object required for understanding, so it needs enough contrast against its background to actually be seen, not just present. A legend or a title tells you what the line represents; neither one helps if the line itself is too faint to trace.
