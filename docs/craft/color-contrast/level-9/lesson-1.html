Level 9, Lesson 1: APCA vs. the WCAG 2 ratio

Every ratio you've calculated so far in this course treats color as the only input: one text color, one background color, one number, regardless of whether that text renders at 12px thin or 40px bold. APCA is an alternative scoring method built around a different idea — that how readable a color pair looks depends on the text's size and weight too, not color alone, so the same two colors can score differently depending on how they're actually being used on the page.

A design system has one dark-gray text color used two ways: as bold 15px labels on form fields, and as regular-weight 15px helper text underneath them. Both uses sit on the same white background. A standard ratio checker reports the exact same number for both, since the color pair is identical. An APCA-based checker, however, scores the bold labels noticeably higher than the regular-weight helper text. Why the difference?

A traditional ratio is pure color math — it can't see the font at all, so it returns the same number whether the text is thin or bold. APCA is built to account for how weight and size change legibility, scoring heavier or larger text more favorably than thinner or smaller text set in the exact same colors. That's the core difference: one method measures the color pair, the other measures the color pair as it's actually being rendered.
