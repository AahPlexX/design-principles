Level 8, Lesson 3: Placeholder text dark enough to be mistaken for a real value

Placeholder text has an odd job: readable enough to work as a hint, but light enough that nobody confuses it for something already typed in. Most contrast advice pushes placeholder color lighter to hit a minimum ratio — but a placeholder can pass every ratio check and still fail its actual purpose by looking exactly like real, entered data.

An email field's placeholder, "you@example.com", is styled in #4b4b4b — the same color used for real, typed-in text elsewhere on the same form — and it clears the body-text contrast minimum easily. During testing, several people leave required fields blank because they believed the fields were already filled in. What actually went wrong?

A contrast ratio measures legibility, not identity — it can't tell a hint from an answer. If placeholder text and real input text share a color, weight, and size, the field looks filled in even when it isn't. The fix is a visible gap between the two: placeholders sit clearly lighter than real values, while still landing above the minimum needed to be read at all.
