Level 8, Lesson 5: Toast/tooltip dismiss icons too faint against their own background

A toast or tooltip carries its own background color, wherever it happens to pop up on the page. A dismiss icon styled once, from a shared "secondary icon" style built for a different, lighter background, and then reused everywhere, is only ever tested against the background it was designed for — not the one it actually lands on.

A success toast has a dark green fill, with a white checkmark icon and a dismiss "X" styled at low opacity white — the same "secondary icon" style used across the product's white cards, where it looks appropriately quiet. Against the toast's own dark green background, that same "X" is nearly invisible. Why did this slip through?

A shared style token carries a color value, not a guarantee — it was tuned for one background and nothing stops it from being dropped onto a different one where the math no longer works. The fix isn't avoiding shared styles; it's checking the token's contrast again in every new background it gets placed on, the same way a color has to be re-checked in light mode and dark mode separately.
