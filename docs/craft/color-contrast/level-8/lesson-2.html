Level 8, Lesson 2: Link color indistinguishable from body text once underline is removed

An underline used to do all the work of saying "this is clickable." Once it's dropped for a cleaner look, a color shift is the only thing left to carry that message — and passing a contrast check against the page background doesn't tell you whether that color shift is even noticeable next to the text sitting right beside it.

Body copy in an article is set in #2b2b2b. An inline link in the same paragraph is set in #3a3a45, with the underline removed, and on its own it clears the body-text contrast minimum against the white page. A reviewer signs off, calling it compliant. What did that check miss?

A color this close to the surrounding text can pass a background contrast check and still fail the job a link color exists to do: standing out from the words around it. Once the underline is gone, either keep enough color distance to be obvious at a glance, or bring back a non-color cue — an underline, a weight change — so the link doesn't depend on a color difference alone to be found.
