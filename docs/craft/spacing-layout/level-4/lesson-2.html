Level 4, Lesson 2: Margin collapsing

You've set margin-bottom: 24px on every paragraph in an article, and margin-top: 40px on every heading, expecting a clean 64px of air above each heading. When you check the rendered page, the gap is only 40px. Nothing is broken — this is how block-level elements (elements like p, h2, and div that each stack on their own line and stretch full width) have always behaved when they touch.

Two paragraphs sit directly next to each other in normal document flow, with no padding, border, or other content between them. The first has margin-bottom: 24px; the second has margin-top: 40px. How tall is the actual visible gap between them?

This is margin collapsing: when two block-level elements in normal flow touch edge to edge, with nothing (no padding, border, or in-flow content) sitting between them, their vertical margins don't add up — they merge into one margin sized to whichever value is larger. Here that's 40px, so the paragraph's 24px effectively contributes nothing extra. This only applies to vertical margins between elements in normal document flow — it doesn't happen to horizontal margins, and it doesn't happen to flex or grid items, which is one reason gap behaves more predictably inside those layouts.
