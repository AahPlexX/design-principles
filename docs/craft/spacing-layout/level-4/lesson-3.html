Level 4, Lesson 3: box-sizing: border-box

You set a card to width: 240px, add padding: 20px so the content inside doesn't touch the edges, and give it a 2px border. You expected a 240px-wide card. Instead it measures 284px, and now three of them no longer fit in a 720px row. The box-sizing property decides what that width value actually measures — and by default, padding and border aren't part of it.

A card is styled with: 

.card {
  width: 240px;
  padding: 20px;
  border: 2px solid;
  box-sizing: border-box;
}

How wide does the card actually render on screen?

Without box-sizing: border-box, the default (content-box) treats width as the content area only — padding and border get added on top, so this card would render at 284px (240 content + 20+20 padding + 2+2 border). With border-box, the 240px you set is the final, total width: the padding and border live inside that measurement, and the content area is whatever's left over (196px here). The box's footprint never grows past the width you declared — only the content area gets smaller to absorb the padding and border.
