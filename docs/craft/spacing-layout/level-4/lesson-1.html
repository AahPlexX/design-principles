Level 4, Lesson 1: gap vs. margin-per-child

You've built a row of filter chips inside a flex container, and you gave every chip margin-right: 12px so they don't touch. It looks fine until you notice the whole row sits 12px further right than every other element on the page — because that last chip still has its own trailing margin, with nothing after it to justify the space.

Three tag buttons sit inside a flex container. Each button has margin-right: 12px so they don't touch. What's the visible result, and what's the more resilient fix?

A block-level element (one that stacks and takes up its own row or column, like a div or button in a flex row) keeps whatever margin you give it, including the last one in a row — CSS has no built-in awareness of "this is the final item, skip its margin." gap works differently: it only inserts space between children, never on the outer edges of the row, so a row of any length lines up flush on both ends with no leftover space to trim.
