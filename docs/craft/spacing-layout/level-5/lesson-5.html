Level 5, Lesson 5: Density has a floor

A team shrinks the padding around a row of icon buttons in a mobile toolbar so one more icon fits in the same width. In testing, people using the app on their phones start tapping the icon next to the one they meant to.

What's the most likely cause of the mis-taps after the toolbar's padding was tightened?

Density has a floor. Tightening spacing to fit more on screen works right up until the gap between tappable elements gets so small that a finger — much less precise than a mouse pointer — can't reliably hit the one it was aimed at. On a desktop table, tight rows are still easy to click because a cursor is a single precise point; on a touch toolbar, the same tightness shrinks each icon's effective tap area below a comfortable, reliable size, and neighboring taps start colliding. The fix isn't a bigger icon on its own — it's enough surrounding space that a fingertip has real room to land.
