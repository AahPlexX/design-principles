Level 5, Lesson 2: A gap alone can replace a border

A dashboard used to separate its Revenue, Users, and Errors widgets with a 1px solid border between each one. The redesign removes those borders, keeps each widget's own heading, and widens the gap between widgets from 16px to 32px. Nothing else changes.

After the redesign — no borders, same headings, 32px between widgets instead of 16px — does the dashboard still read as three separate sections?

A visible border is a heavier signal than most layouts need. A gap that's clearly wider than the space used inside each widget, paired with each widget's own heading, already tells the reader "these are different groups" — the same proximity rule that groups a label with its input also separates unrelated blocks once the gap between them grows past what's used inside either one. Removing the border here doesn't remove structure; it removes a line that was repeating a signal the spacing already sent.
