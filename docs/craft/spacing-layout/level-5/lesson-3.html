Level 5, Lesson 3: The isolation effect

A sidebar lists four account settings — Profile, Password, Notifications, Connected Apps — each separated from the next by 12px. Below the list, a "Delete account" link sits 40px below Connected Apps, instead of the same 12px used between the other rows.

The four settings rows are each 12px apart. "Delete account" sits 40px below the last one. What does that extra gap do to how "Delete account" reads?

Proximity works in both directions. Items placed close together read as one group, and an item that gets noticeably more surrounding space than its neighbors reads as separate from that group — this is sometimes called the isolation effect. Here, "Delete account" isn't structurally part of the settings list above it; the 40px gap is what tells the reader that, before they've even registered what the link does.
