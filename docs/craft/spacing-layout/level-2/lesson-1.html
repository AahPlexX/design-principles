Level 2, Lesson 1: Why a fixed scale beats nudging it until it looks right

A teammate hands you a component library where every gap was set in the moment — 13px here, 15px there, 22px somewhere else, each one nudged until it "looked right" in that one frame. Nothing is obviously broken. But something about the whole page feels a little off.

A designer sets each component's spacing by eye — 13px here, 15px there, 22px somewhere else — adjusting every value until it looks right on its own, with no shared scale behind any of them. What happens across the whole page?

Picking spacing values by eye, per component, is a named mistake for exactly this reason: without a shared scale, a page ends up with dozens of near-identical gaps (13px here, 15px there) that read as sloppy even though no single one looks wrong in isolation. The fix is to pick every spacing value from one fixed scale — like multiples of 4px or 8px — so every gap on the page stays visually related to every other gap.
