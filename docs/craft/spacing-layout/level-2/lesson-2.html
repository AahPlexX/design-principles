Level 2, Lesson 2: 4pt vs. 8pt grid — the two conventions

A checkout page needs generous gaps between sections — 8px, 16px, 24px, 32px all read as comfortably roomy. But inside one button, an icon sits tight against its label, just 4px away. An 8px-only scale has no value that small. Do you break the rule for one button, or was the whole scale built on the wrong unit?

A design system needs to express both roomy section gaps (8, 16, 24, 32px) and a tight 4px gap between an icon and its label, all from one consistent scale. Which base unit makes every one of those values a clean multiple of the same number?

8px and 4px are the two common base units for a spacing scale, and the choice comes down to how fine your smallest gap needs to be. An 8px base (8, 16, 24, 32, 40, 48...) gives fewer choices and keeps decisions fast for products that stay fairly roomy. A 4px base (4, 8, 12, 16, 24, 32...) is really the same idea at finer resolution — it can still produce every value the 8px scale can, plus the smaller in-between values that dense components like icon-and-label pairs need. Rounding 4px up to 8px isn't a real fix — it just replaces one arbitrary gap with a different one. The point of either convention is the same one from the last lesson: every value on the page comes from a single declared unit, whichever size that unit is.
