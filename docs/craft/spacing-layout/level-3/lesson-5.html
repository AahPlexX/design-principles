Level 3, Lesson 5: Column grids

A product page splits its width into a 12-column grid: the main content spans the first eight columns, a sidebar spans the last four. A developer asks why the space between the article and the sidebar uses one CSS value, while the space between the whole grid and the edge of the browser window uses a different one.

A layout uses a 12-column grid: the main article spans columns 1 through 8, and a sidebar spans columns 9 through 12. What's the difference between the grid's "gutter" and its "margin"?

A column grid divides a page's width into equal vertical slices, and a component spans however many of those slices it needs — the article above spans 8 of 12, the sidebar spans the remaining 4. The gutter is the fixed gap between columns, keeping neighboring pieces of content (the article and the sidebar) from touching. The margin is a separate fixed gap between the outer edge of the entire grid and the edge of the screen or its container, giving the whole layout breathing room from the edge — the same margin the checklist calls for so nothing touches the screen edge on mobile. Twelve is a common column count specifically because it divides evenly by 2, 3, 4, and 6, so a layout can split into halves, thirds, quarters, or sixths without any column being an odd fraction.
