Level 5, Lesson 2: Dashboards — one primary metric vs. supporting metrics

A dashboard's whole job is to answer a question fast — but a screen with six numbers all the same size doesn't answer anything, it just hands someone a list to read one by one. The same one-dominant-element rule that governs a single button applies at dashboard scale: pick the number that matters most for this screen, and let everything else sit visibly behind it.

A sales team's dashboard shows five stat cards in a single row — Revenue, Active Users, Churn Rate, New Signups, and Avg. Session Length — every card the exact same size, font weight, and color. The team's stated goal for this screen is "let people see at a glance whether revenue is on track." What's the hierarchy problem?

Making every card equally prominent is the same mistake as making every heading bold — if everything stands out, nothing does. Since the team already knows Revenue is the priority, that card should visibly outrank the rest: a larger number, a distinct card treatment, or placement first in reading order, while Active Users, Churn Rate, Signups, and Session Length stay present but smaller and quieter.
