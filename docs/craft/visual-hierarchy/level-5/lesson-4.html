Level 5, Lesson 4: Mobile constraints force stricter hierarchy

On a wide desktop screen, elements can sit side by side with room to spare, so two things of similar size don't necessarily compete — there's enough space between them that the eye treats them as separate. On a narrow phone screen, that same content usually gets stacked into a single column, one thing directly above the next, which means anything that wasn't already clearly ranked now competes head-on.

On desktop, a recipe page shows a large photo on the left and, off to the side in its own column, an equally sized "Rate this recipe" card. The spacing between them is wide enough that the photo still reads as the clear focal point. On the phone version, the layout simply stacks the same two elements vertically at their original sizes — photo, then immediately below it, the same "Rate this recipe" card, with almost no gap between them. What's the mobile hierarchy problem?

The desktop layout's hierarchy was working, but partly for a reason that doesn't survive the switch to mobile: wide horizontal space kept two same-sized elements from directly competing. Once a narrow screen forces everything into one column, that buffer is gone, so the two elements need to be re-ranked on their own terms — for example, shrinking the rating card and adding clear vertical spacing so the photo still reads as dominant.
