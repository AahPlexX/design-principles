Level 6, Lesson 1: DOM order vs. visual (CSS) order mismatch

Hierarchy isn't only visual. CSS can make a page look correctly ordered to a sighted mouse user while the underlying HTML tells a completely different story to anyone navigating by keyboard or screen reader.

A page's HTML lists the main article first, then a sidebar. In CSS, the sidebar gets order: -1 so it displays visually above the article. What breaks for a screen reader or keyboard user?

Screen readers and keyboard tab order follow the DOM (the HTML source order), not the visual CSS order. A sighted mouse user sees the sidebar first; a keyboard or screen-reader user still gets the article first — two genuinely different experiences of the same page's hierarchy.
