Level 6, Lesson 3: Color alone must never be the only signal of importance

A dashboard flags overdue invoices by turning their row text red — every on-time invoice stays the same dark gray, same font, same size, same position, just a different color. That reads instantly for a reader with typical color vision. It fails silently for anyone with color blindness (a meaningful share of readers, more common in men than women), for anyone viewing the dashboard in glare that washes out color differences, and for anyone using a screen reader, which can't announce a color at all.

An order table marks canceled orders by making their status text red. Every other status — shipped, pending, delivered — is plain dark-gray text, same weight, same size. A warehouse manager with color blindness scans the table and can't reliably tell canceled orders apart from the rest. What's the actual design problem here?

The fix isn't finding a "better" color — any single color, used alone, fails for someone who can't distinguish it from the rest. The status column needs a second, non-color signal alongside the red text: the word "Canceled" spelled out, an icon like a strikethrough or an X, or a distinct pattern. Color can still add emphasis on top of that second signal — it just can never be the only thing carrying the meaning.
