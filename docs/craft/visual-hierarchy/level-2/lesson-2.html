Level 2, Lesson 2: Similarity

A settings screen lists five rows, each with a gray icon and gray label, styled identically. Nobody decided that one of them should matter more than the rest — but if a sixth row shows up with a bright blue icon while the other five stay gray, that row now reads as the important one, whether or not that was the plan.

A navigation bar has five links, all the same size, weight, and color. A sixth link for a new feature gets added, and to make sure people notice it, someone sets it in bold text with a darker color than the other five. What happens to the bar's hierarchy?

Similarity is what tells a viewer "these are the same kind of item, worth the same attention" — a row of identically styled links reads as one equal tier. The instant one item breaks that shared styling, it visually separates itself from the group and reads as outranking the rest, even if the goal was just "make it noticeable," not "make it the most important link on the page." If every link should carry equal weight, they need matching styling; if one link genuinely should outrank the others, breaking similarity on purpose is exactly the right tool — the risk is doing it by accident.
