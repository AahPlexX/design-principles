Level 1, Lesson 4: Color and saturation as a signal

Saturation is how vivid or washed-out a color looks — a bright orange is high-saturation, a dusty beige is low-saturation, even if both are technically "orange." A small, high-saturation element can out-compete a much bigger, muted one, because a vivid color surrounded by muted neighbors is exactly the kind of thing eyes are drawn to first.

A settings page has seven buttons, all the same size and shape. Six of them — things like "Change password" and "Export data" — are styled in muted gray. The seventh, "Upgrade to Pro," is styled in vivid orange. What effect does this have on the page's hierarchy?

Color and saturation work as a hierarchy signal independent of size — a small vivid element can out-rank a larger neutral one. That's also why it backfires the same way oversizing everything does: if all seven buttons were vivid orange, none of them would stand out, and the page would need a different signal to show which action actually matters most. One saturated color, used deliberately on the one thing that deserves the attention, is what makes this work.
