Level 1, Lesson 1: The one-dominant-element rule

A screen only has one "most important" thing at a time. The moment two elements are styled with equal visual weight — same size, same boldness, same color intensity — the reader has to stop and work out which one actually matters, instead of just knowing.

A checkout page has two buttons, styled identically: <button class="btn-primary">Buy now</button> and <button class="btn-primary">Add to wishlist</button>, sitting side by side. What's wrong?

"Buy now" is the primary action this page exists for; "Add to wishlist" is a real but secondary option. Giving them the same weight (same button style) removes the visual decision the page should have made for the reader — style the primary action as a filled button and the secondary one as a plain text link instead.
