Level 1, Lesson 3: Contrast (light/dark value) as a signal

"Contrast" here means how different an element's lightness is from what's around it — a near-black element against a white background pops; a medium-gray element against that same white background barely registers. This is a separate idea from the color-contrast ratio a screen-reader-friendly page has to meet — that ratio sets a legibility floor everything must clear. This lesson is about using extra value contrast, on purpose, to make one element outrank its neighbors.

An invoice page lists several line items, then the total amount due below them. Every line — the line items and the total — is set in the exact same light-gray text, at the exact same size. What's the hierarchy problem?

The total is the one number on this page someone is most likely to look for. Rendering it in near-black text while the line items stay in a lighter gray — same size, same font, just a darker value — gives the total more visual weight without changing anything else about it. That's value contrast working as a hierarchy signal, separate from whether either color meets a minimum legibility requirement.
