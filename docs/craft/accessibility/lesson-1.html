Lesson 1: Keyboard reachability

Everything a mouse can click, a keyboard must be able to reach and activate too. Native elements like <button> and <a> do this automatically; a generic element with a click handler does not.

A "Submit" control is built as <div onclick="submitForm()">Submit</div>. What's the accessibility problem?

A <div> has no built-in keyboard behavior — Tab skips right past it, and there's no way to "click" it with Enter or Space. Swapping it for a real <button> fixes this for free, with no extra ARIA or JavaScript needed.

Full explanation: Accessibility.
