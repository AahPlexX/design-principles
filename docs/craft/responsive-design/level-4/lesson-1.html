Level 4, Lesson 1: Fluid images preventing overflow

A layout can pass every breakpoint test and still break the moment a real photo drops in. Grid and Flexbox reflow text and boxes automatically, but an <img> has no such instinct — left alone, it renders at whatever pixel width the file was saved at, container be damned.

A product photo saved at 1600px wide is dropped into a card component with width: 300px on mobile. No other image-specific CSS exists. What actually happens in the browser?

Images have no built-in awareness of their container — an <img> renders at its intrinsic size unless CSS says otherwise. The fix is a single rule: img { max-width: 100%; height: auto; }. That caps the image at its container's width and lets the height scale to match, so it shrinks along with everything else instead of overflowing it.
