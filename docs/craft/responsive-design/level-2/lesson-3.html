Level 2, Lesson 3: Clamping type between a floor and a ceiling

clamp() lets one line of CSS do what used to take a handful of media queries: a floor value, a ceiling value, and a formula for everything in between. Reading what it actually renders at a given width just takes doing the math once.

A hero heading is styled with font-size: clamp(1.5rem, 5vw, 4rem);. On a 320px-wide phone, with the root font-size at its usual 16px, 5vw works out to 16px — smaller than the 1.5rem minimum (24px). What size does the heading actually render at on that phone?

clamp(min, preferred, max) evaluates the preferred value first, then checks it against the floor and the ceiling. Here the viewport-based preferred value (16px) undershoots the 1.5rem floor (24px), so the browser uses the floor instead — the heading renders at 24px, not 16px. On a very wide screen, the same declaration would instead hit the 4rem ceiling. Everywhere in between those two extremes, it's the fluid vw value itself, all without writing a single media query.

Full explanation: Responsive Design.
