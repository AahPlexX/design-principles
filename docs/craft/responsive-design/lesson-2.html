Lesson 2: Sizing touch targets for a finger, not a cursor

Testing a layout with a mouse hides a problem that only shows up once someone tries it on a real phone: a fingertip is a much blunter tool than a cursor's single pixel. A button that felt perfectly clickable on a laptop screen can turn into a frustrating miss-then-retry once it's tapped instead of clicked.

A mobile nav bar uses icon buttons that are 28×28px. In testing on a laptop, clicking them with a mouse pointer works perfectly every time. Is that enough to call the buttons done?

A link or button under about 44×44px is hard to tap accurately with a finger, even if it's perfectly clickable with a precise mouse cursor. Mouse testing can't catch this — the target needs to be checked (or sized) for touch specifically, not assumed safe because a cursor never missed it.
