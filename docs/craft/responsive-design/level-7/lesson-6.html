Level 7, Lesson 6: Foldables and ultra-wide monitors as the spectrum's far ends

"Every screen" doesn't stop at the widths a typical breakpoint set already covers. A folding phone can open into something wider than it is tall mid-session, and a very wide or very large monitor can leave a fixed max-width layout stranded in a narrow column with acres of empty space on either side. Both are still just points on the same spectrum — the fix is the same discipline already covered earlier in this course, applied further out.

A layout was breakpointed for "phone," "tablet," and "desktop." On a very large desktop monitor, the content sits in a narrow centered column with wide empty margins on both sides. What's the responsive-design fix?

A device name was never the real target — the layout breaks (or, here, stops using the space it has) at a specific point, and that's where the next breakpoint belongs. A very wide monitor and a folded-open tablet are both just widths outside the ones already planned for, not a special case that needs its own separate rulebook.

Full explanation: Responsive Design.
