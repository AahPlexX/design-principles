Level 7, Lesson 4: Orientation change and text-resize/zoom as test cases too

"Every screen" isn't only about width — the same phone can be rotated to a much shorter, wider viewport, and the same layout can be handed a much larger text size by a reader who enlarges it for their own eyesight. Both change the space a layout has to work with just as much as swapping devices does, so both deserve their own pass through your testing, not just a check at a fixed portrait width and a fixed font size.

A settings screen with a confirmation dialog looks correct on a phone held upright (portrait). Rotated to landscape — same phone, now wider but much shorter — the dialog's "Save" and "Cancel" buttons are pushed below the bottom edge of the screen with no way to scroll down to reach them. What does this reveal about the layout?

A layout tested only in portrait can quietly assume there's always plenty of vertical room. Landscape rotation on that same phone removes most of that room without changing the width much at all — if the dialog has no way to scroll or reflow when height runs short, content gets stranded off-screen even though nothing about the device itself changed except how it's being held.

Full explanation: Responsive Design.
