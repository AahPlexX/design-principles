Level 1, Lesson 1: One layout vs. a build per device

Some teams handle "responsive" by building two separate sites — one at a mobile subdomain for phones, one at the main domain for everything else — instead of one layout that adapts. That split creates a maintenance problem the single-layout approach never has.

A shop runs two separate builds: a mobile subdomain for phones and the main domain for everyone else. Marketing updates the homepage sale banner on the main domain but forgets to update the mobile version. A phone visitor sees last week's price. What's the real problem with this setup?

One adaptive layout has only one place to update, so the sale banner would have changed everywhere at once. Two separate builds mean two places to remember, and eventually one gets missed — exactly what happened here.
