Level 1, Lesson 2: There's no "standard" screen size

Design briefs used to say "design for a 320-pixel-wide screen" back when that covered nearly the whole market. Today, phones alone ship in a wide spread of widths, before tablets, laptops, and desktop monitors even enter the picture.

A designer sets a single target: "the layout should look perfect at 390 pixels wide, the width of a common phone." Real visitor data shows screen widths spread continuously from around 320 pixels to well over 1400, with no single width covering anywhere near a majority of visitors. What does this tell the designer about that plan?

Screen width is continuous, not a small set of standard sizes, and it hasn't been a small set for a long time. A layout tuned to look perfect at exactly 390 pixels is only ever exactly right at that one number, and increasingly wrong the further a real visitor's screen gets from it.
