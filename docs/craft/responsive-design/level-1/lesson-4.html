Level 1, Lesson 4: The viewport meta tag

A page can have flawless flexible CSS — percentages, Grid, wrapping — and still look broken on a phone, because the browser was never told to use the phone's actual width in the first place.

A site's CSS uses percentage widths and CSS Grid, and it looks correct on a laptop. On a phone, though, it loads zoomed out — the whole layout, just shrunk down and tiny — and the visitor has to pinch-zoom to read anything. The page's <head> has no viewport meta tag. What fixes it?

Without a viewport meta tag, mobile browsers assume the page was built for a wide, desktop-style layout and render it at that width, then shrink the whole thing down to fit the screen — which is why everything looks tiny and forces a pinch-zoom. The flexible CSS was never the problem; the browser just wasn't told to use the phone's real width.

Full explanation: Responsive Design.
