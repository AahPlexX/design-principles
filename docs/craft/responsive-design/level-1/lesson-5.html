Level 1, Lesson 5: The mobile 100vh bug

A full-screen mobile section can measure correctly in the CSS and still get cut off in the browser, because "100% of the viewport height" means something different on a phone than the number on screen at any given moment.

A mobile hero section is set to height: 100vh, with a "Get Started" button positioned near its bottom edge. Whenever the phone's address bar is visible, the bottom of the hero — including the button — is pushed below the visible screen, and the visitor has to scroll to find it. Why does this happen, and what's the fix?

Mobile browsers show and hide UI like the address bar as someone scrolls, so the visible viewport height actually changes while 100vh stays fixed at the larger, chrome-hidden value. 100dvh (dynamic viewport height) tracks the real visible height as it changes, so a full-screen section — and anything pinned near its edge — stays actually on screen.

Full explanation: Responsive Design.
