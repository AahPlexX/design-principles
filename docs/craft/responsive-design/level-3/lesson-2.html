Level 3, Lesson 2: Mobile-first vs. desktop-first media queries

A breakpoint has a direction, not just a position. Writing min-width queries starts from the smallest screen and adds rules as space opens up; writing max-width queries starts from the widest screen and takes rules away as space shrinks. Same breakpoint, opposite amount of undoing.

A developer builds a three-column layout as the base CSS, then adds @media (max-width: 600px) rules to collapse it to one column on a phone. A teammate suggests flipping it around: write the one-column layout as the base, then add @media (min-width: 600px) rules to add columns back for wider screens. What's the real advantage of the second approach?

Base styles apply to every screen width, including ones no media query happens to cover. In the desktop-first version, the base is the three-column layout — so the phone has to override and undo those rules just to get back to something simple. In the mobile-first version, the base is already the simple one-column layout, and each wider breakpoint only adds columns rather than fighting a layout meant for a bigger screen.
