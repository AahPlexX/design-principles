Level 6, Lesson 1: Text that only shrinks instead of reflowing when the column narrows

When a column runs out of horizontal room, there are two very different ways to respond: let it narrow and let the same text wrap onto more lines, or leave its width alone and shrink the font until the old line breaks still fit. Only one of those keeps the text easy to read.

A card's body copy sits in a column that's 320px wide on desktop. On a phone, the layout stacks, so that column is free to stretch to the phone's full width — but instead of letting the paragraph wrap onto more, shorter lines, the CSS keeps the column pinned at 320px and drops to font-size: 11px in a mobile media query so the same line breaks still fit. What's the actual fix here?

The column never needed to stay 320px wide on a narrower screen. Letting it grow to the available width and wrapping the same paragraph onto more lines keeps the text at a normal, readable size. Shrinking the font instead makes it harder to read while solving nothing a wider, wrapped column wouldn't have solved on its own.

Full explanation: Responsive Design. For deeper practice sizing type overall, see the Typography course.
