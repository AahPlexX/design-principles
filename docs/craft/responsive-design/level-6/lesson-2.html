Level 6, Lesson 2: Fluid type scales via clamp() instead of jumping at breakpoints

A font size doesn't have to sit still between breakpoints. It can grow and shrink continuously as the viewport changes width, instead of snapping from one fixed value to the next the instant a breakpoint is crossed.

A heading currently uses three fixed sizes across three breakpoints: 24px below 600px, 32px from 600–999px, and 40px at 1000px and up. Replacing all three with a single declaration, font-size: clamp(1.5rem, 4vw, 2.5rem);, changes what?

clamp(min, preferred, max) uses the middle value — here a viewport-relative 4vw — but never lets it go below the min or above the max. That means the size changes continuously as the viewport width changes, with no visible jump at any particular width, so the breakpoints simply aren't needed for this property anymore.

Full explanation: Responsive Design. For deeper practice sizing type overall, see the Typography course.
