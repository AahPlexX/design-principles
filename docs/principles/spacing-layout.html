Spacing & Layout

Spacing is the empty room you leave around and between things. Layout is how you arrange them. Together they're the main tool for showing a reader which things are related without needing a label or a border to say so.

Why it matters

The human eye groups things that are close together and separates things that are far apart — this is automatic, not a preference (it's one of the Gestalt principles of perception, "proximity"). If a form's label sits closer to the field above it than the field it actually belongs to, people will misread which label goes with which field, no matter how clear the wording is.

The core rule

Space between related items should always be smaller than the space between unrelated groups of items. And pick spacing values from a fixed scale (like multiples of 4px or 8px) instead of ad hoc numbers — it keeps every gap on the page visually related to every other gap, instead of looking randomly inconsistent.

Good vs. bad

Good 
.field { margin-bottom: 24px; }  /* between fields */
.field label { margin-bottom: 8px; } /* label to input */

The gap between a label and its own input (8px) is clearly smaller than the gap between one field group and the next (24px) — proximity tells the reader what belongs together before they even read the labels.

Bad 
.field { margin-bottom: 16px; }
.field label { margin-bottom: 16px; }

Equal spacing everywhere means there's no visual signal for which label belongs to which input — the reader has to figure it out from position and guesswork alone.

Common mistakes

  • Equal spacing everywhere. If every gap on the page is the same size, nothing reads as "grouped" — the layout looks like a uniform grid of unrelated pieces.
  • Centering everything. Center alignment has no consistent edge for the eye to follow down a page; left-aligned (in LTR languages) text and controls give the reader one vertical line to scan.
  • Picking spacing values by eye, per component. Without a shared scale, a page ends up with dozens of near-identical gaps (13px here, 15px there) that read as sloppy even though no single one looks wrong in isolation.
  • Cramming content edge-to-edge on mobile to "fit more in." Removing margin on small screens doesn't create more usable space — it removes the breathing room that makes content feel readable rather than crowded.
  • Using borders or background colors to separate sections instead of space. A visible line is a heavier signal than most page structure needs; often a gap alone (or a gap plus a heading) does the job with less visual noise.

Checklist

  • Related items sit closer together than unrelated items.
  • Spacing values come from one scale (e.g. 4, 8, 12, 16, 24, 32, 48px), not arbitrary numbers.
  • Page content has consistent margin on mobile — nothing touches the screen edge.
  • Alignment is consistent: one clear left (or right, for RTL) edge per column of content.
  • A section break is legible from spacing alone, before adding a border or background.
Go deeper

The 8-point grid: a common convention is to make every spacing and sizing value a multiple of 8px (or 4px for finer adjustments). This isn't a hard technical requirement — it's a discipline that makes a design system's spacing choices predictable and easy to reuse across a whole product.

Gestalt principles beyond proximity: similarity (things that look alike are read as related), common region (a shared background or border groups items), and alignment (items sharing an edge are read as connected) all combine with spacing to communicate structure without words.

CSS tools that encode this directly: flexbox's gap and grid's gap apply consistent spacing between children without needing margin on individual items (which can double up unpredictably at the edges of a row).
